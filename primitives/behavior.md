# Primitive: Behavior

An observable response pattern that is the fundamental unit of analysis.

```yaml
behavior:
  name:
  description:
  frequency:
  severity:
  task_classes:
  trigger_conditions:
  observable_outputs:
  consequences:
```

## Rules

- A behavior is inferred from **observable outputs and trigger conditions**, never from imagined internal motives (`../SKILL.md` core doctrine).
- Distinguish a single occurrence from a recurring tendency; attribution requires reproduction (`../flows/reproduce.md`).
- Classify each behavior as trait-like, state-like, environment-induced, or interaction-induced (`../flows/characterize.md`).
- Behaviors are facts; explanations are hypotheses.

Examples: premature completion declaration · ignoring contradictory operator observation · creating centralized abstractions during repeated feature additions · retrying without changing diagnostic strategy.
